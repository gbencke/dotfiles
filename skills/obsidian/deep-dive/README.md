# Deep Dive

Generate a deep-dive technical document from meeting transcripts and summaries in the Obsidian vault.

## Output

```
01.Technical/product/deep dives/deep-dive-<topic-slug>.md
```

## Structure

The skill follows a strict 16-section template:

1. Core Problem
2. What [TOPIC] Is
3. Classic vs. NewGen
4. Key Architectural Decisions
5. Topic-Specific sections
6. Impact on Downstream
7. Synchronization Gaps
8. Feature Flag Behavior
9. Open Questions
10. Blockers & Dependencies
11. Concerns Flagged
12. Stakeholders & Positions
13. Key Quotes
14. Confluence Documentation
15. Timeline
16. *(omit sections with no evidence)*

- `SKILL.md` — the full instructions and attribution rules.
