# Possibility Analysis

Explore the solution space before deciding which path to take.

## What it does

- Resists premature closure.
- Surfaces hard, soft, and assumed constraints.
- Maps dimensions of variation (build vs buy, centralized vs distributed, short vs long term, etc.).
- Expands possibilities, then converges on the viable frontier.

## Phases

1. **Frame Acquisition** — identify the core question, constraints, and dimensionality.
2. **Divergent Phase** — maximize breadth and depth of options.
3. **Convergent Phase** — apply constraints, tradeoffs, and judgment.

## Files

- `SKILL.md` — the full epistemic process.
- `package.json` — skill metadata.
- `references/` — supporting notes on cognitive models, domain patterns, and uncertainty handling.
