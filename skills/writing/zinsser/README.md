# Zinsser

Rewrite text using William Zinsser's *On Writing Well* method.

## What it does

- Strips clutter: qualifiers, redundant pairs, throat-clearing, inflated phrases.
- Enforces clarity, brevity, simplicity, and humanity.
- Prefers active voice and concrete words.

## When to use

- "zinsser this", "apply zinsser", "clean up my writing", "rewrite with zinsser", or `/zinsser`.

## Files

- `SKILL.md` — the Zinsser method and rewrite procedure.
