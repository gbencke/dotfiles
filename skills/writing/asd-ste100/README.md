# ASD-STE100 Simplified Technical English

Rewrite text into ASD-STE100 Simplified Technical English (STE), a controlled language for technical documentation.

## What it does

- Restricts vocabulary to approved words, one meaning per word.
- Enforces active voice and short sentences.
- Applies strict rules for procedures and safety instructions.
- Adds scaled ASCII charts and diagrams (bars, timelines, flows, decision trees) wherever the text has numbers, sequences, or structures.

## When to use

- "simplify to STE", "apply simplified technical english", "make this STE compliant", or `/ste`.
- Writing STE reports or investigations that need illustrative ASCII charts.

## Files

- `SKILL.md` — the STE rules and rewrite procedure.
