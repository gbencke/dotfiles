# Writing Skills

Prose and technical-writing skills that rewrite text against a defined style standard.

## Skills

| Skill | What it does |
|-------|--------------|
| `asd-ste100` | Rewrite text into ASD-STE100 Simplified Technical English: approved words, one meaning per word, active voice, short sentences, ASCII charts and diagrams. |
| `po-pm-writing` | Write for Product Owners and Project Managers: bottom line first, the ask stated outright, technical detail turned into impact, scope, dates, and risk. |
| `zinsser` | Rewrite text using William Zinsser's *On Writing Well* method: strip clutter, enforce clarity, brevity, and simplicity. |

Each skill is a `SKILL.md` prompt with rules and examples.
