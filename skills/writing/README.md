# Writing Skills

Prose and technical-writing skills that rewrite text against a defined style standard.

## Skills

| Skill | What it does |
|-------|--------------|
| `asd-ste100` | Rewrite text into ASD-STE100 Simplified Technical English: approved words, one meaning per word, active voice, short sentences. |
| `zinsser` | Rewrite text using William Zinsser's *On Writing Well* method: strip clutter, enforce clarity, brevity, and simplicity. |

Each skill is a `SKILL.md` prompt with rules and examples.
