# Find Skills

Help discover and install agent skills from the open skills ecosystem.

## What it does

- Answers "how do I do X", "find a skill for X", "is there a skill that can...".
- Checks the skills leaderboard and runs CLI searches.
- Guides installing a skill with `npx skills add`.

## Skills CLI

```bash
npx skills find [query]
npx skills add <package>
npx skills check
npx skills update
```

Browse skills at https://skills.sh/.
