# Programming Languages

Language-specific skills for writing and reviewing code.

## Skills

| Skill | What it does |
|-------|--------------|
| `c4-repo-doc` | Generate a C4-model architecture document for the current repo (context, container, component, code levels, and call graph) as Markdown and interactive HTML. |
| `golang-arch` | Apply Go monorepo and hexagonal architecture decisions for 10–50 service codebases. |
| `golang-general` | Apply a structured Go code review checklist during PR review, design review, or self-review. |

The Go skills are `SKILL.md` prompts with rules, examples, and checklists. `c4-repo-doc` also generates documents from the repo it runs in.
